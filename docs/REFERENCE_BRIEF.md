# SA-02 · Kailasa / Ellora Cave 16 reference brief
**Not a survey-grade reconstruction.** Research accessed 2026-11-02. Scope is the Cave 16 excavated precinct only. This is a spatial interpretation, not a scan, conservation record, original-colour restoration, or accurate sculpture catalogue.
